# A股监控系统（神奇九转 + 量能 + LOF溢价 → 微信推送）

四层架构：`domain`(纯计算) / `application`(编排调度) / `infrastructure`(数据·存储·推送) / `presentation`(消息·图表)。

## 快速开始

```bash
cd stock_monitor
pip install -r requirements.txt

python main.py demo      # 离线演示：合成数据跑通全流程（无需网络，立即可跑）
python main.py scan      # 实盘扫描：akshare→baostock→合成数据 三级降级
python main.py schedule  # 常驻调度：15:35收盘扫描 / 10:30,14:00盘中 / 16:00心跳
python main.py rank vol_ratio day   # 排行：量比/额比/成交额/溢价/turn_abs × 日/周/月
python main.py lof 161005           # 单只LOF溢价评估
python main.py heartbeat           # 手动心跳检查
python main.py stats               # 信号胜率统计（10日窗口）
python main.py web                 # Web界面 http://127.0.0.1:8000
                                   # 功能：自选池排行(日/周/月)·K线九转(多周期)·
                                   # 在线搜索(股票/ETF/LOF)·数据来源·信号与扫描日志·
                                   # LOF溢价走势图·运行日志·功能测试(自测/离线演示/心跳/手动扫描)
python tests/webtest.py            # Web接口自动化冒烟(需先启动web)
python tests/selftest.py           # 53项自测（含网址查看/图表渲染/图片推送）
```

## 配置（config.yaml）

- `watchlist`：自选股票与LOF，代码自动识别类型
- `push.channels`：`console` / `serverchan` / `pushplus` / `wecom_bot`，填入自己的Key即生效
- `signal.push_levels`：直推级别（默认S/A，B级进晚报）
- `schedule`：各任务时刻，错过自动补跑
- `chart_enabled`：信号K线卡/LOF溢价卡渲染开关（mplfinance 可用时生效）

## 核心规则

- 九转：`Close[i] vs Close[i-4]` 连续9根同向即完成结构；含8/9极值验证(perfection)
- 六层过滤：趋势(ADX/布林带宽) → 周期共振 → 量价模型×4 → 指标共振(MACD/RSI/BOLL/KDJ) → S/A/B/C分级+止损 → 市场状态动态阈值
- LOF溢价：IOPV > 双口径估算净值（中间价/离岸汇率两轨）> 昨净值 三级降级；含溢价分位、份额流向、仓位自校准
- 溢价历史：每日快照落库（`premium_hist`），分位优先用落库真实序列计算；Web端可查60日溢价走势
- 推送增强：信号卡附同型历史胜率与信号K线图（MA5/止损线/量比高亮/九转标注）；LOF提醒附溢价走势图；企微机器人支持图片消息（base64+md5≤2MB），文字卡先行、图片增强随后
- 告警：16:00心跳检查收盘扫描；扫描过半标的失败时独立告警（不受每日推送限额）
- 存储：SQLite（WAL），K线增量落库、推送去重、信号5/10/20日收益自动回填、LOF溢价历史快照

## 策略说明

### ① 神奇九转（TD Sequential 简化版）
- 计数：当日收盘价与前4根收盘价比较，连续9根同向即完成九转结构
- 方向：上涨结构（高9）=顶部衰竭→卖出参考；下跌结构（低9）=底部衰竭→买入参考
- 极值验证(perfection)：第8或9根的极值须包住第6/7根，否则计数顺延一根，过滤假结构
- 计数≥6 才开始标注并进入深度分析（`nine_turns.show_from=6 / min_focus=6`）

### ② 六层信号过滤（逐层漏斗）
| 层 | 名称 | 规则 | 作用 |
|---|---|---|---|
| L1 | 趋势过滤 | ADX<40 且布林带宽>5% | 趋势过强/过窄时九转失效，直接降级 |
| L2 | 周期共振 | 周线九转同向 +2分 | 多周期互相印证 |
| L3 | 量价模型 | 放量上攻/缩量回调/滞涨放量/恐慌砸盘 | 量价配合打分 |
| L4 | 指标共振 | MACD背离/RSI极值/布林触碰/KDJ交叉 | 多指标共振加分 |
| L5 | 分级止损 | S≥8/A≥5/B≥2/C；止损=结构极值外2% | 输出可执行建议 |
| L6 | 动态阈值 | 牛市宽松/熊市严格（量比、RSI门槛） | 适应市场状态 |

### ③ 量能三级过滤
1. 粗筛：量比≥2.0 或 换手≥3倍20日均 或 额比≥2.5倍（任一命中）
2. 分位：当日量进入60日窗口90%分位以上
3. 精筛：量比≥1.5 确认有效放量——三级全过才判"放量"，避免单日脉冲误判

### ④ LOF/ETF 溢价监控
- 净值三级降级：IOPV > 双口径估算净值 > 昨官方净值
- 估算模型：`净值 ≈ 昨净值 ×(1 + 底层资产涨跌×仓位系数 + 汇率变动×外币敞口)`
- 双口径：官方（中间价）vs 参考（离岸CNH），两轨差即不确定性
- 提醒：溢价≥3%提醒 / ≥5%警告；折价≤-2%套利；60日分位≥95%极端
- 份额流向：高溢价+份额单日+5% → 套利盘进场、溢价收敛在即
- 自校准：官方净值披露后回测误差，自动修正仓位系数

### ⑤ 推送纪律与胜率回测
- S/A级直推（附信号K线图），B级进晚报；同标的同方向冷却5个交易日；每日限额12条
- 每个信号自动跟踪5/10/20日收益并回填，信号卡展示同型历史胜率（10日窗口）

### ⑥ 运行时序
`09:35 市场状态 → 10:30/14:00 盘中巡检 → 15:35 收盘扫描 → 16:00 心跳告警`（错过自动补跑）

## 微信推送 → 看板打通

推送卡（Server酱/PushPlus/企微机器人）会附带看板深链 `• 看板详情：http://xxx/?code=600519&period=day`，
微信点开即自动定位该标的的K线九转图、LOF溢价卡与溢价走势图（与电脑网页完全一致）。

打通步骤：
1. 在 `config.yaml` 的 `web.public_url` 填入看板公网地址（留空则不附链接）
2. 看板需公网可达，本机部署二选一：
   - **内网穿透（推荐）**：安装 cpolar/ngrok，执行如 `cpolar http 8000`，把分配的公网地址填入 public_url（免费版地址会变，变更后改配置即可）
   - **公网服务器部署**：把项目拷到云服务器，`python main.py web` 常驻（建议配 systemd/任务计划）
3. 重启服务生效；推送发出后微信里点击链接即可打开看板对应页面

说明：看板为只读+功能测试页，无登录鉴权，请勿将地址公开分享；深链对非自选标的同样有效（自动在线拉取K线）。
